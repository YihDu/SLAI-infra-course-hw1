# Repository guide: two independent stages

Read [START_HERE.md](START_HERE.md) first.

- `stage1/` contains the original assignment, validated cand-155, generators,
  evidence, local environment and submission archives. Read its `AGENTS.md`.
- `stage2/` contains the second assignment and starter. Read its `AGENTS.md` and
  `START_HERE.md`, then the official Background, statement, ISA and ABI.
- Run each stage's commands from its own directory. Do not mix evaluator,
  environment, program format or packaging rules. Submission ZIPs retain the
  contract's root paths, without a stage directory wrapper.
- Preserve official documents, frozen evaluators and prior measured artifacts.
  Historical absolute paths remain evidence; map the old root to `stage1/`
  when reproducing old work. Do not rewrite historical reports or traces.
- Predictions are not measurements; local grades are not organizer scores.
  Keep failed attempts and fresh output directories. Never fabricate evidence.
- Documentation/reorganization is not an optimization experiment.

The existing user instruction limits trace collection to one complete native
export of the current primary conversation. Do not collect extra sessions
without revised user authorization. Stage 2 officially asks for broader
relevant records including subagents; resolve that difference before a workflow
depending on broader collection. Preserve existing historical evidence.

At setup on 2026-10-10, Stage 2 has complete starter materials but no personal
evaluated solution. Published reference scores are not our results.
