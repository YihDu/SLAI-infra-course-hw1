## First-round P1 implementation details

Each candidate below passed development functional checks on seeds 7 and 19.
They have not yet passed full HBM race validation. Results, when complete,
are `VARIANT/critpath.json`; failures are `VARIANT/error.json`.

- `merged_n16_v2`: one projection team serves 128 prompt rows. N16 uses all
  16 SMs on width-256 projections; attention still runs separately per batch.
- `merged_n32_v2`: same cross-batch structure with N32; width-256 projections
  use 8 SMs, exchanging parallelism for larger tiles and fewer loads.
- `merged_neuron_mlp`: split FFN neurons across 16 owners. Each owner keeps a
  32x32 activation in RF through W1/GELU/W2, stages its W1/W2 weights in SH,
  and emits a partial 128x256 output. Explicit barrier and sum merge partials.
- `merged_neuron_rfpanel`: improved RF layout keeps the whole 128x64 local
  activation panel in RF0..7 and a 128x32 W2 accumulator in RF8..11. Each W1/W2
  weight tile is reused over all four 32-row blocks, no SH weight staging.
- `parent_tc4x8kp4`: unchanged cand-149 P1 on the D1-faster hardware; required
  before making a shared-hardware decision.

The first merged prototypes (`merged_n16`, `merged_n32`) failed read-before-
write: the first B preload still targeted the old RF1 instead of new RF12.
The v2 versions fix this. Failures and all measured experiments are retained
in the append-only iteration log. An RF packing guard rejected the initial
K32 QKV attempt; the v2 helper supports 4/8/16 tiles per RF lane.
